Data Science project from my first year studying Computer Science, this project involved...

- Selecting an appropriate data set
- Doing an initial formatting to the data so it is appropriate to work with
- Analysing the original data to achieve results
- Cleaning the data, taking into account duplicates, missing data etc
- Reanalysing the data using the now clean data
- Comparing the results between the clean and unclean data

The data was sourced from Kaggle, the data was analysed in excel, all finding were presented in a PowerPoint.
